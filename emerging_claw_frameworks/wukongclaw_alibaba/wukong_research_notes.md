# 阿里悟空企业级 Agent 平台调研笔记

> Sources: 知乎/新浪财经/东方财富 | Date: 2026-03-17

## 核心定位
全球首个**企业级 AI 原生工作平台**，定位为"把龙虾装进企业"。
独立应用 + 内置到超 2000 万企业组织的钉钉中。

## 组织架构
- 阿里成立 **Alibaba Token Hub (ATH) 事业群**，吴泳铭挂帅
- 千问事业部、悟空事业部归入 ATH 事业群
- 悟空事业部定位："打造 B 端 AI 应用入口，将模型能力深度融入企业工作流"

## 核心技术特性

### 1. 企业级安全运行环境
- AI Agent 自动继承企业权限规则
- 所有操作在安全沙箱中运行
- Token 消耗与成本实时可查（"像管预算一样管 AI 开支"）

### 2. 钉钉 CLI 化改造
- 钉钉重写底层代码，进行全面 CLI（命令行界面）化改造
- 悟空 Agent 能原生操作钉钉上千项能力
- 非模拟人类点击 GUI，而是直接调用 CLI 接口
- 实现"沟通即执行"

### 3. Skill 生态
- 推出 AI 能力市场：开发、审核、上架、分发全链路
- 全面兼容开源 Skill 体系
- 目标：全球最大的 toB Skill 市场
- 阿里系 B 端能力逐步接入：淘宝、天猫、1688、支付宝、阿里云

### 4. OPT 十大行业解决方案
OPT = One Person Team（一人团队），首批覆盖：
电商、跨境电商、知识类博主、开发、门店、设计、制造、法律、财税、猎头

交付物 = "场景化 Skill 套件 + 预编排工作流 + 行业数据沉淀"

### 5. 多端支持
- PC 端 + 手机端
- PC 端安装后打造完整 AI 工作环境
- 通过本机连接公司工作网络和内部系统
- 后续支持微信、Slack 等全球主流 IM 平台

## 与 OpenClaw 的关系
悟空是阿里基于 OpenClaw 理念打造的企业级封装版，核心差异在于：
1. 天然长在企业组织中（钉钉生态）
2. 内置企业权限管控
3. 安全沙箱运行
4. 成本可视化
5. 行业解决方案开箱即用

## 钉钉 CEO 陈航原话
"今天，我们把钉钉打碎，用AI重建，炼出'悟空'。过去是人用钉钉来工作，未来是AI用钉钉来工作。"
