# 精选办公类 Top 10 热门好用 Skills 深度调研

**作者**: Damon Li
**日期**: 2026-03-13

## 1. 调研背景

在 ClawHub 数千个技能中，办公类（Productivity）是竞争最激烈、质量最参差不齐的领域。本报告通过对 GitHub 收藏量、ClawHub 下载量及社区反馈的综合评估，精选出 10 个真正具备“生产力工具”属性的 Skills。

## 2. 精选 Skills 列表与核心功能

| 排名 | Skill 名称 | 核心功能 | 推荐理由 |
| :--- | :--- | :--- | :--- |
| 1 | **Smart-Calendar-Manager** | 自动同步 Google/Outlook 日历，智能识别冲突并建议调整。 | 解决了多平台日历同步的痛点，支持自然语言预约。 |
| 2 | **Meeting-Summarizer-Pro** | 接入 Zoom/Teams 转录文本，自动生成结构化纪要、待办事项及责任人。 | 纪要提取准确度极高，支持多语言总结。 |
| 3 | **Email-Inbox-Automator** | 自动分类邮件，基于历史回复风格生成草稿，紧急邮件自动提醒。 | 极大地减少了处理垃圾邮件和常规回复的时间。 |
| 4 | **Document-Auto-Refactor** | 自动检查文档格式、语法错误，并根据预设风格（如：学术、商务）重写。 | 提升了文档产出的专业度，支持 Markdown 和 Word。 |
| 5 | **Personal-Knowledge-Base** | 自动抓取网页、PDF 内容并建立向量索引，支持跨文档语义搜索。 | 打造了 Agent 的“第二大脑”，知识检索速度极快。 |
| 6 | **Linear-Sync-Master** | 深度集成 Linear，自动将对话中的任务转化为 Issue，并跟踪进度。 | 研发团队必备，实现了从对话到任务管理的无缝衔接。 |
| 7 | **Daily-Briefing-Gen** | 每天早晨自动汇总天气、日程、未读邮件及行业新闻，生成语音/文字简报。 | 提供了极佳的仪式感和信息获取效率。 |
| 8 | **Excel-Data-Wizard** | 通过自然语言操作 Excel，支持复杂的公式生成、数据清洗和图表绘制。 | 降低了非专业人士处理大数据的门槛。 |
| 9 | **Slack-Workflow-Bot** | 在 Slack 频道中自动响应指令，触发审批流或查询内部数据库。 | 增强了团队协作的自动化程度。 |
| 10 | **Voice-Memo-Transcriber** | 将语音备忘录实时转录为文字，并自动提取其中的关键想法。 | 适合碎片化灵感的捕捉。 |

## 3. 核心功能深度拆解

### 3.1 智能日历管理 (Smart-Calendar-Manager)
该 Skill 不仅仅是简单的 API 调用，它内置了冲突解决算法。当用户说“帮我约一个下周三下午有空的时间”时，它会横向对比所有关联日历，避开专注时间（Focus Time），并自动预留路程时间。

### 3.2 会议纪要专家 (Meeting-Summarizer-Pro)
其核心竞争力在于其 `SKILL.md` 中精妙的 Prompt 设计。它采用了“两阶段提取法”：第一步提取所有事实性陈述，第二步基于事实生成行动项（Action Items），有效避免了 AI 的幻觉问题。

## 4. 总结

这 10 个 Skills 代表了目前 OpenClaw 办公生态的最高水平。它们共同的特点是：**API 稳定、Prompt 鲁棒、场景聚焦**。对于初学者，建议从日历和邮件管理开始上手。
