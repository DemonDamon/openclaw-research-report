# OpenClaw「App」榜单，国产Skill下载量冲上第一：能给龙虾接入现实世界

> 来源：机器之心，2026年3月13日
> 链接：https://mp.weixin.qq.com/s/rbigQZU5XyoCWNd2P6sJ9Q

## 核心观点提取

### 1. ClawHub 生态现状
- ClawHub 上已有 **22,000+** 个 Skill
- Skill 质量参差不齐，普通用户"望而却步"
- 只有少数 Skill 可称为"基础设施"，搜索工具是其中之一

### 2. 搜索类 Skill 是"基础设施"
- 搜索 Skill 的核心作用：为智能体装上"连接现实世界"的眼睛和"检索记忆"的海马体
- 只有先通过搜索获取最新、最准确的现实增量数据，智能体随后的逻辑推理、工具调用和交付才具有实际意义
- 智能体对信息的容错率极低——一旦搜索 Skill 抓取了虚假、过时或低质量内容，后续自动化任务崩溃

### 3. 国产 Skill vs 海外 Skill
- **海外 Skill 管"通用"**：提供基础的网页抓取骨架
- **国产 Skill 拼"精准"**：本土语境下的精准能力
  - 中文内容理解深度
  - 本地知识库覆盖广度（政务、权威媒体、学术站点）
  - 与国内主流内容平台的协同整合
- Brave Search 等海外搜索引擎在中文互联网中只能抓取表层信息，频频出现中文语意理解偏差导致的"AI 幻觉"

### 4. 百度 ClawHub 生态矩阵（全球下载量第一的搜索引擎官方 Skill）
- **百度搜索 Skill**：https://clawhub.ai/ide-rea/baidu-search，中文搜索首选，提供免费额度
- **百度百科 (Baidu Baike)**：结构化权威词条，适合背景调查和知识问答
- **百度学术 (Baidu Scholar)**：学术检索，适合写论文、追前沿课题
- **Video AI Notes（视频 AI 笔记）**：拆解视频核心内容与会议纪要
- **文心衍生 PaddleOCR 文档解析 Skill**：超高精度文档内容提取与理解
- **文字识别 Skill**：为智能体装上"眼睛"
- **百度电商 Skill**：跨平台比价与选购决策
- **百度地图 Maps Skills**：空间感知与导航能力

### 5. 实测场景
- 实测1：足球智能观赛助手（百度搜索 + 百度百科，并发调用）
- 实测2：欧战预测分析（基于搜索结果的深度推理）
- 实测3：搜索特定媒体文章
- 实测4：演唱会信息查询与购票
- 实测5：科技新闻深度解读

### 6. 核心结论
- "得搜索者得天下"的逻辑在智能体时代依然成立
- 搜索基础能力的精准度，直接决定了整个智能体应用的智商下限
- Agent 赛道重心正在向工程化落地与本地适配转移
- 好用的基础设施组件，是决定智能体应用能否投入生产环境的关键
- 国产基础能力 Skill 已走向成熟，以中文用户为核心的本土 Agent 应用层正在形成
