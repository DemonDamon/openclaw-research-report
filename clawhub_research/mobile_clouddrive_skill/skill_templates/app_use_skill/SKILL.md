# App-Use-Skill 框架设计

**作者**: Damon Li
**版本**: 1.0.0

## 1. 概述

`App-Use-Skill` 是一个通用的“App 操作代理层”框架，其核心思想是让 AI Agent 能够像人类一样，通过“看”和“点”来操作任何移动 App，即使该 App 没有提供 API。

## 2. 核心架构：VLM-driven UI Automation

本框架基于**视觉语言模型 (VLM)** 驱动的 UI 自动化，其工作流程如下：
1.  **截图与标注 (Screenshot & Annotation)**: Agent 获取当前 App 界面的截图，并由 VLM 识别出所有可交互的元素（如：按钮、输入框、列表项），并为其打上标签。
2.  **指令理解 (Instruction Understanding)**: Agent 理解用户的自然语言指令（如：`帮我点一下“确认”按钮`）。
3.  **行动规划 (Action Planning)**: Agent 将用户指令与截图中的元素进行匹配，规划出具体的操作步骤（如：`tap(element_id=12)`）。
4.  **指令执行 (Action Execution)**: Agent 调用底层的自动化框架（如：Appium, `atl-browser`）来执行点击、输入、滑动等操作。

## 3. 关键技术挑战

| 挑战 | 解决方案 |
| :--- | :--- |
| **元素定位不准** | 结合 OCR 和元素层级信息进行多模态定位。 |
| **动态界面处理** | 引入“等待-重试”机制，处理 App 加载动画和网络延迟。 |
| **滚动与翻页** | 训练 VLM 理解“滚动条”等视觉线索，实现长列表的遍历。 |
| **状态保持** | 记录每一步操作的历史截图，构建一个视觉化的“记忆链”。 |

## 4. 与移动云盘 App 的结合

通过 `App-Use-Skill`，Agent 可以直接操作移动云盘 App 的界面，实现以下高级功能：
-   **自动登录**: 识别用户名/密码输入框并自动填充。
-   **分享文件**: 找到“分享”按钮，选择分享渠道（如：微信），并发送给指定联系人。
-   **协作邀请**: 在协作文档中，找到“邀请成员”按钮，并输入协作者的邮箱。

## 5. 总结

`App-Use-Skill` 的愿景是打破 App 之间的信息孤岛。通过将 UI 自动化与 VLM 相结合，我们可以赋予 AI Agent 操作任何 App 的能力，从而真正实现跨应用的自动化工作流。
