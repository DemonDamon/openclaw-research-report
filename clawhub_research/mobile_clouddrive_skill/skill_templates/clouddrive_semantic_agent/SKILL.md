# CloudDrive-Semantic-Agent Skill

**作者**: Damon Li
**版本**: 1.0.0

## 1. 概述

本 Skill 旨在将移动云盘从一个简单的文件存储工具，升级为一个具备语义理解能力的智能文件助手。它不仅能执行基本的文件操作（上传、下载、搜索），更能理解用户的自然语言指令，并基于文件内容进行复杂的整理、归纳和问答。

## 2. 核心能力

### 2.1 语义文件搜索
-   **指令**: `帮我找一下上周关于“电网安全”的会议纪要PPT`
-   **实现**: 调用云盘的全文搜索 API，并结合 LLM 对文件名和文件内容进行二次筛选，找出最匹配的结果。

### 2.2 智能文件整理
-   **指令**: `把“项目A”文件夹里所有的合同，按签订日期创建一个子文件夹并归档`
-   **实现**: 遍历文件夹，通过 OCR 或文本提取识别文件内容中的日期信息，然后执行文件移动和重命名操作。

### 2.3 跨文档内容问答
-   **指令**: `对比一下“合同A”和“合同B”在违约条款上的主要区别`
-   **实现**: 同时加载多个文档内容到上下文中，让 LLM 进行对比分析并生成摘要。

## 3. 实现逻辑

本 Skill 采用“**API 调用 + LLM 后处理**”的混合模式。
1.  **API 调用**: 与移动云盘的官方 API 对接，执行基本的文件操作。
2.  **LLM 后处理**: 将 API 返回的结构化数据（如：文件列表）和非结构化数据（如：文件内容）喂给 LLM，进行语义理解和决策。

## 4. 依赖

-   移动云盘官方 API 密钥
-   具备长文本理解能力的 LLM (如：Claude 3, GPT-4)
-   可选：OCR 服务 API (用于识别扫描件)

## 5. 示例 Prompt

```
你是一个智能云盘助手。你的任务是理解用户的自然语言指令，并将其转化为对云盘文件的操作。

用户指令: {{user_input}}

可用工具:
- `search_files(keyword)`: 搜索文件
- `move_file(source_path, target_path)`: 移动文件
- `read_file(file_path)`: 读取文件内容

请规划你的行动步骤，并调用合适的工具来完成任务。
```
