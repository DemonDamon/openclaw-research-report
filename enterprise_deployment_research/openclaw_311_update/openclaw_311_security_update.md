# OpenClaw 2026.3.11 安全更新调研报告：权限管控与审计机制

## 1. 版本背景
针对 2026 年 2 月以来工信部及国家互联网应急中心发布的多次安全预警，OpenClaw 社区于 2026 年 3 月 11 日发布了重大安全加固版本。该版本核心目标是解决“信任边界模糊”和“权限过高”的顽疾。

## 2. 核心安全更新特性
本次更新引入了多项企业级安全特性，显著提升了在敏感环境下的可控性：
- **浏览器来源验证 (Origin Validation)**：强制对所有 WebSocket 连接进行来源校验，有效防御跨站请求伪造（CSRF）和恶意网页指令诱导。
- **细粒度权限委托 (Fine-grained Delegation)**：支持对 Skill 的调用进行硬件级隔离和权限细分，AI 智能体不再拥有宿主机的全量权限。
- **默认加固配置文件 (Hardening Profile)**：新版本默认禁用了高风险操作（如直接编辑系统文件、执行未授权终端命令），用户需显式开启。
- **审计日志增强**：记录所有 AI 决策路径及对应的系统资源调用，为事后溯源提供完整证据链。

## 3. 针对工信部预警的修复情况
针对预警中提到的“恶意指令接管”和“信息泄露”风险，3.11 版本通过以下机制进行对冲：
- **指令审批流**：对于涉及敏感目录或系统配置的指令，引入了人工确认（Human-in-the-loop）机制。
- **凭证加密存储**：优化了 Gateway 令牌和 API Key 的存储逻辑，防止因端口暴露导致的凭证直接泄露。

## 4. 电力内网部署建议
- **版本选择**：必须使用 2026.3.11 或更高版本，严禁使用旧版默认配置。
- **网关隔离**：即使在内网，也应配置强 Gateway Token，并限制仅允许特定 IP 段访问控制 UI。
- **Skill 审计**：对所有引入内网的第三方 Skill 进行静态代码扫描和动态行为审计。
